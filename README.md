# How This Page Was Built — Through The Years

A single-file, dependency-free interactive guide to six eras of web development. The running example is one tiny to-do list, rebuilt from static HTML through React, Vite, and TypeScript.

Open `index.html` in any modern browser. No install, build step, external font, CDN, analytics, storage, or network request is required.

## Interaction

- Choose a labeled era directly, drag the era slider, or use the arrow, Page Up/Down, Home, and End keys.
- Add and check items in the live to-do specimen.
- Light and dark themes follow the operating-system preference.

## Privacy

The page collects nothing and sends nothing. To-do items exist only in memory and disappear when the page reloads.

## Deploy

This repository can be served as a static site from any host, including GitHub Pages. Use `index.html` as the entry point.

## Build signoffs

Substantial agent runs append a timestamped signoff inside the page. Each entry names the lead and subagent roles, the models that powered them when the runtime exposes that information, and the work each seat completed. Unknown model IDs are marked unknown rather than guessed.
